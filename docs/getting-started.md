# Getting Started with MDMbox

MDMbox provides master data management for healthcare organizations, helping maintain accurate and consistent patient and provider data.

## What is MDMbox?

MDMbox provides:

- **Patient Matching** - Probabilistic and deterministic matching algorithms
- **Record Linkage** - Link records across multiple sources
- **Golden Record** - Single source of truth for entities
- **Data Quality** - Deduplication and data cleansing

## Quick Start

1. Contact us at [health-samurai.io/contacts](https://health-samurai.io/contacts) to get access
2. Configure matching rules for your use case
3. Integrate MDMbox with your data sources
